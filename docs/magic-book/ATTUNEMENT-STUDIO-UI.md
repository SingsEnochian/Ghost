# Attunement Studio — UI Spec

Attunement Studio is where a reader teaches the book how to recognise them and what their cadences mean.

## Screen 1 — Status / entry
Shows current profile, listening state, last recognised cadence and active book mode. The visual language is quiet when dormant and gains orbital geometry when the book is awake.

## Screen 2 — My Signature
A profile-binding ritual. The user records the same cadence three times; the Studio visualises timing, zones and consistency, then stores a tolerant pattern. This is personalisation, not sole authentication.

## Screen 3 — Gesture Recorder
A large open-book target records taps, holds and traces. A live strip shows each primitive, zone and gap. The user can retry, trim accidental steps and name the cadence.

## Screen 4 — Assignment
The user assigns an action, scope, sensitivity and feedback profile. Actions may target Magic Book, ArcSweep, Runa, Glyph Forge, Observer or a volume. Protected actions visibly require confirmation.

## Screen 5 — Practice
The Studio hides configuration detail and lets the user perform the cadence repeatedly. It reports recognised / partial / missed, timing drift and the zone that failed. The goal is a ritual a human can actually repeat.

## Screen 6 — Feedback & feel
Choose visual, sound and haptic responses. Preview options include ink ripple, sigil flare, orbital wake, page whisper, world-hum seed, single pulse, double pulse and slow swell.

## Screen 7 — Accessibility
Controls for timing tolerance, region size, one-handed mode, fatigue mode, low-motion mode and haptic/audio substitutions. Every programmed action also exposes a normal control.

## Screen 8 — Receipts
Shows recognised cadences, confidence, action result and context. Receipts are inspectable and deletable according to the eventual provenance policy.

## Interaction law
The page looks like a book until it has something to say back. Attunement UI therefore appears in margins, seals and orbital linework rather than permanent dashboard chrome.
